FoxxGram / Apps

FoxxGram Applications

FoxxGram apps are built in the open and can be checked against published source. Anyone can confirm that a store build matches the code we release.

Mobile apps

  • FoxxGram for Android
  • FoxxGram for iPhone and iPad

Desktop apps

  • FoxxGram for macOS
  • FoxxGram for Windows / Mac / Linux

Web apps

  • FoxxGram Web A
  • FoxxGram Web K

FoxxGram Database Library

  • FGLib — a cross-platform client library for custom apps
  • FoxxGram X for Android — a sleek experimental client

Community apps

  • NorthGram, a Windows-focused community client
  • FoxxGram CLI for Linux
  • FieldProto, a community library

Source code

Publishing the code lets researchers review how encryption is implemented. It also lets you check that the version you install is built from the same source we share.

FG
FoxxGram Database Library

A cross-platform library for building custom FoxxGram apps. Designed so other teams can ship their own clients on the same network.

A
FoxxGram for Android

The official Android app. Available as a store build or a direct package for people who want to install it themselves.

i
FoxxGram for iOS

The official iPhone and iPad app, built for the usual Apple devices you already use.

M
FoxxGram for macOS

A native Mac client, kept in step with the mobile apps so your chats stay current.

K
FoxxGram for web browsers — Version K

A full web client for Mac, Windows, Linux, and mobile browsers.

A
FoxxGram for web browsers — Version A

A second official web client, also available on desktop and mobile browsers.

D
FoxxGram Desktop

A desktop client for Windows, Mac, and Linux, built for people who live in a window on their computer.

X
FoxxGram X for Android

An experimental Android client built on the shared library, with a sharper, lighter interface.

Community apps

C
FoxxGram CLI (community)

A command-line client for Linux, maintained by the community.

N
NorthGram (community)

A community client optimized for Windows.

F
FieldProto (community)

A community library for people building their own tools on the protocol.

Security research program

FoxxGram welcomes developers and researchers who want to review the apps, the service, and the protocol. If you find a real issue, we want to hear about it.

FoxxGram
FoxxGram is a cloud-based mobile and desktop messaging app with a focus on speed and privacy.
